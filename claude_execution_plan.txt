# Implementation Plan: Dual-Column Dashboard, Per-Question Timer & Solution Peek, and Responsive Math Puzzle Topic

## Context
The goal is to enhance the exam preparation platform with three key capabilities:
1. **Home Page Dual-Column Layout**: Organizes the home dashboard into two side-by-side vertical columns: Real Full-Length Mock Tests on the left, and AI-Generated / Topic Tests on the right (stacking vertically on mobile viewports).
2. **AI Test Per-Question Timer & Non-Blocking Solution Peek**: Adds a customizable countdown timer for each individual question (e.g. 60s) alongside the overall/section exam timer. When the individual question timer expires, the question remains 100% active and attemptable, and an option button "💡 View Solution & Explanation" is unlocked allowing the user to view the step-by-step reasoning on-demand.
3. **Math Puzzle Topic & Responsive Geometric Structure Engine**: Introduces "Math Puzzle & Geometric Logic" into the placement topic catalog, designs schema and renderer support for visual geometric diagrams (crisp vector SVGs with responsive `viewBox`), bundles a 15-question visual logic test (`MATH_PUZZLE_TEST`), and renders diagrams in both the Live Exam and Post-Exam Review.
