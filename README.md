# Mr. Assessment

A clean, minimalist technical assessment and exam prep platform inspired by top corporate recruitment test environments (HackerRank, Mercer Mettl, TCS iON).

## 🚀 Features

- **Authentic Exam Simulator**:
  - Full-screen distraction-free assessment environment.
  - Placements ITM 7-Section Pattern (Reasoning Ability, Quantitative Aptitude, Verbal Ability, Pseudo Code, Numeric Puzzles, English Grammar, English Writing).
  - Countdown timer with live warnings and section-strict auto-advance pacing.
  - Interactive Question Palette with live color states (Answered, Unanswered, Marked for Review, Not Visited).
- **Subjective Essay / Email Editor**:
  - Dedicated writing interface for Section 7 with live word counter and character counter.
- **Diagnostic Analytics & Weak Topics Engine**:
  - Automatically analyzes test performance against syllabus topics (e.g. Syllogisms, Time & Work, Bitwise Operators, Prepositions).
  - Identifies critical weak areas needing revision.
  - Section-wise SVG performance charts and sectional cutoff verification.
  - Full question-by-question solution review with explanations.
- **Zero Backend / Zero Setup**:
  - 100% pure client-side HTML, CSS, and Vanilla JavaScript.
  - Ready for instant deployment on Vercel.
  - LocalStorage persistence for test history and score tracking.

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**
- **Vanilla CSS3** (Corporate Assessment Minimalist White Theme)
- **Zero external dependencies** (no npm build steps required)

## 📦 Deployment

Deploy directly to [Vercel](https://vercel.com):
- Framework Preset: `Other`
- Root Directory: `./`
- Build Command: None (Static Site)
